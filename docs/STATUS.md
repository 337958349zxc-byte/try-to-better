# 当前状态与验证范围

更新日期：2026-11-05。Android预览版本0.2.21 / code23；初始公开快照基线为0.2.19。

## 真实桌面大肥鱼

0.2.21新增独立系统悬浮窗、用户授权、前台服务与通知关闭。入口“我的 → 桌面大肥鱼”，开启后回到手机桌面，角色仍显示；支持透明完整角色、拖动贴边、原作逐帧互动、气泡及独立设置。聊天仍为本地模拟，不接入API或真实日程。[使用与实现](pet/ANDROID_PET_OVERLAY_V1.md)、[实际桌面截图](pet/OVERLAY_SCREENSHOTS.md)、[验证记录](pet/verification/overlay-build-and-ui.json)。

新增权限限定为SYSTEM_ALERT_WINDOW与FOREGROUND_SERVICE_SPECIAL_USE，独立服务不复用闹钟逻辑。已执行真实系统授权拒绝/允许、返回Launcher、拖动/关闭、可用显示区域变化及通知关闭检查；实体手机旋转和现代Android后台策略仍待验收。

## 大肥鱼桌宠视觉预览

新增独立 `feature/petpreview/`，由“我的”页进入。包含透明完整角色、逐帧动作、拖动吸边、轻气泡、离线模拟聊天、示例计划/执行、设置及授权查看。所有示例与真实业务数据分离，不新增悬浮窗权限、服务、数据模型或 AI API。[设计与交付说明](pet/ANDROID_PET_DESIGN_V1.md)、[实际截图](pet/SCREENSHOTS.md)、[验证记录](pet/verification/build-and-ui.json)。

已验证构建、32项相关单元检查、393dp和360dp各2项隔离界面检查、96个素材帧的透明边界与哈希。真机安装体验、系统悬浮窗、AI接入与商用底层角色权利确认仍需后续处理；模拟器结果不代表小米真机验收。

## 重要限制

- 姿态计数的真实准确率、持续会话性能和动作质量评分没有完成验证。
- 小米系统时钟取消有已知失败；App提醒和系统时钟交接需分别观察。
- 手机实际安装、后台、同步和导出体验仍需验收。
- 课程、菜单和专业内容交接尚依赖外部工作流。
- 当前是局域网/个人原型，远程、多用户、正式支付和商业留存尚未验证。
